# Personal Self-Learning AI Agent

هوش مصنوعی شخصی با قابلیت یادگیری مداوم، پایگاه دانش اختصاصی و رابط کاربری وب مدرن (بر پایه Flask و Tailwind CSS).

### قابلیت‌ها:
1. **سیستم یادگیری (Self-Learning)**: امکان ثبت فکت‌ها، قوانین و ترجیحات جدید در حافظه هوش مصنوعی.
2. **رابط کاربری وب مدرن**: چت تعاملی و پنل مدیریت حافظه به صورت زنده.
3. **پایگاه دانش پایدار**: ذخیره خودکار آموخته‌ها در فایل محلی JSON.
